# 🌿 Planto – Plant E-commerce UI/UX Design

![App Preview](images/plant.png.png)

## 📌 Overview
This is a UI/UX design project for a plant e-commerce website designed using Figma. The goal was to create a clean, modern, and nature-inspired shopping experience.

## ❗ Problem
Users often find plant shopping websites cluttered, confusing, and difficult to browse products easily.

## 💡 Solution
Designed a minimal and intuitive interface that improves product browsing, enhances visual clarity, and makes the shopping experience smooth and enjoyable.

## 🔄 User Flow
User opens website → browses plants → selects product → views details → adds to cart → checkout

## 🎨 Design Process
- User Research  
- Wireframing  
- UI Design in Figma  
- Prototyping  

## ✨ Features
- Clean product browsing  
- Nature-inspired UI  
- Simple navigation  
- Product card layout  
- Smooth shopping experience
